## Why

Every clipboard manager on the market breaks your flow. You copy something, switch apps, paste, then hunt through `Win+V` history with arrow keys or dig into a tray menu. Multi-step. Modal. Slow.

**Edge-Drop removes the friction.** It anchors to the screen edge of your monitor as a transparent, always-on-top, click-through surface. When your cursor approaches the edge, the shelf springs open. Drag images, file stacks, rich text, and HTML bundles *out* of it: directly into whatever desktop app you are already using. No shortcuts. No window switching. No modal dialogs.

It is built for the developer and creative workflow where you constantly juggle screenshots, code snippets, file paths, design assets, and reference links between many windows at once.

## Quick Start

### Prerequisites
- **Node.js** v18 or higher
- **OS**: Windows, macOS, or Linux

### Run from source
```bash
git clone https://github.com/imsovikde/Edge-Drop.git
cd Edge-Drop
npm install
npm run dev          # launches Electron + Vite HMR
```

### Type-check
```bash
npm run typecheck    # runs tsc --noEmit against both node and web configs
```

### Test suite
```bash
npm test             # executes all unit and integration Vitest suites
```

### Build Windows installers
```bash
npm run build:github # outputs an NSIS .exe for GitHub releases
npm run build:store  # outputs an MSIX package for Microsoft Store submission
```

> [!NOTE]
> On Windows, if packaging fails with `EBUSY: resource busy or locked`, close any running Edge-Drop instances first: `taskkill /F /IM electron.exe /T`.

## Features

### Zero-Click Edge Hover & Screen Geometry
- **Frameless Edge Anchor:** Transparent, always-on-top `BrowserWindow` anchored at `x=0`, right screen edge, or top screen dock.
- **100% Click-Through When Collapsed:** Zero interference with background apps; desktop stays completely usable.
- **Configurable Hot-Zone & Blade Geometry:** Adjustable trigger zone height (25% / 40% / 60% of screen) and blade height (50% to 80%).
- **Edge Trigger Proximity Slider:** Range slider (1px to 7px) allowing precise pixel calibration of the edge sensor region.
- **Independent Edge Trigger Placement:** Align trigger strip to **Top**, **Center**, or **Bottom** relative to the shelf, with dynamic CSS `clipPath` calculation.
- **Proximity Beacon:** Subtle 1.5px hairline gradient pulse on the screen edge when touching misaligned vertical boundaries, guiding your cursor to the shelf.
- **Multi-Monitor Single Source of Truth:** Select any physical display with real-time physical resolution calculation (3840x2160, 2560x1440, 1920x1080) across all High-DPI Windows display scaling factors.
- **Rest-as-Intent Seam Policy:** Intelligent 140ms dwell threshold for interior monitor boundaries. Moving your cursor between displays passes through smoothly without accidental shelf triggers, while stopping deliberately at the edge opens the shelf instantly.
- **Versioned Screen Geometry & Probe:** Replaced asynchronous display queries with a pure geometric screen probe (`stickProbe.ts`) backed by versioned display-change caching, eliminating boundary seam jitter across mixed-DPI monitor arrays.
- **Cross-Reboot Display Persistence:** Edge-Drop remembers your chosen monitor across device restarts via a 4-tier resolution pipeline.
- **Top Screen Edge Dock:** Horizontal dock layout (up to 1080px wide) with its own trigger zone, flares, preview flyout, and settings layouts.
- **Smart Windows Fullscreen Game Detection:** Native Win32 `SHQueryUserNotificationState` OS detection (`fullscreen.ts`) combined with `GetForegroundWindow` and `GetClassNameA` filtering (`Progman`, `WorkerW`, `Shell_TrayWnd`) automatically suppresses edge hover during Direct3D games (*VALORANT*, *Cyberpunk*, *PowerPoint*) while allowing Edge-Drop to open smoothly on the Windows Home Screen / Desktop.
- **Self-Healing Launch at Login:** Automatic Windows Registry synchronization (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`) strictly quotes executable paths, guaranteeing that usernames or installation paths with spaces launch cleanly on startup.

### Full Text Payload Streaming & Zero Truncation
- **Zero-Truncation Large Text Sync:** Copy text payloads of any length (including 100,000+ character transcripts). Payloads exceeding 300 characters are streamed directly to disk payloads (`payloads/<id>.txt`), with full fidelity preserved in cloud synchronization and `.edvault` v2 exports without inflating RAM.
- **Chronological Sort & Signature Integrity:** Remote cloud pulls and local synchronization maintain strict chronological sort order (`capturedAt` descending), comparing signatures and timestamps to eliminate list scrambling and redundant re-renders.
- **Deterministic Chunked Blob Storage:** Binary image blobs exceeding 700 KB are split into deterministic 700 KB chunks in cloud vault storage, preventing document limit exceptions and verifying reassembly with SHA-256 integrity.

### Zero-Latency Shelf Keyboard Navigation & 1-9 Quick-Paste
- **1-9 Quick-Paste Hotkeys:** Press `1` through `9` while the shelf is open to immediately paste the corresponding recent card into your active app.
- **Illuminated Alt Keycap Badges:** Holding the `Alt` key smoothly illuminates subtle, Apple-inspired monospace index badges (`[1]` to `[9]`) on the first nine cards.
- **Full Arrow & Action Navigation:** Navigate cards with `ArrowUp` / `ArrowDown` (or `ArrowLeft` / `ArrowRight` on the top dock), press `Enter` to paste, `Space` to open/close the preview flyout, `Delete` to remove an item, and `Esc` to collapse the shelf.
- **Card Shimmer Skeletons:** Smooth shimmer skeleton states render during cloud and local asset hydration to preserve fluid 60fps/120fps visual stability.
- **Viewport Boundary & Focus Ring Isolation:** Dedicated focus ring with boundary clipping protection prevents card outlines from clipping against shelf edges.

### Real-Time Sync Telemetry & Automated Rolling Backups
- **Sync Telemetry Drawer:** Real-time diagnostics drawer inspecting round-trip ping latency, remote document counts, Write-Ahead Log (WAL) queue status, and active connection health.
- **Automated 5-File Rolling Local Backups:** Background engine creates rolling timestamped backups (`backups/history-YYYY-MM-DD-HHMMSS.edvault`) rotating the last 5 snapshots, with 1-click instant restoration from the settings drawer.
- **Bring Your Own (BYO) Firebase Test Wizard:** Integrated credential validation wizard with instant connectivity and permission testing before saving custom credentials. Follow our step-by-step [Firebase Setup Guide](docs/FIREBASE_SETUP.md) for 1-click security rules and zero-lock-in rollback instructions.
- **1-Click Device Diagnostic Issue Reporter:** Generates pre-filled GitHub issue templates with anonymized OS platform, display geometry, memory working set, and sync engine metrics.

### Pinboard Workspaces & Color-Coded Tag Palettes
- **6 Curated Obsidian Color Tags:** Organize clipboard items into distinct workspaces using 6 bespoke palettes: Ruby, Amber, Emerald, Sapphire, Violet, and Slate.
- **Quick-Tag Palette Flyout:** Rapidly apply, switch, or remove color tags directly from card action menus or preview flyouts with instant keyboard shortcuts (`T`).
- **Tactile Card Accent Strips:** Subtle 2px left-border color accents identify tagged items at a glance without visual clutter.
- **Tag Workspace Filtering Tabs:** Dedicated filter rail allows switching between tag collections with zero-friction keyboard navigation.

### Smart Text Transformations & In-Preview Monospace Editor
- **Pure Algorithmic Text Transformers:** Format copied text with one click: JSON Prettify/Minify, Case Conversion (camelCase, snake_case, kebab-case, UPPERCASE, lowercase, Title Case), Whitespace Normalization (trim, single-space, strip empty lines), and Markdown Table Generator from CSV/TSV data.
- **In-Preview Monospace Editor:** Edit clipboard snippets directly inside Preview Flyout with syntax-ready JetBrains Mono monospace font, real-time word and character counters, line metrics, and `Ctrl+S` / `Cmd+S` instant save.

### Clipboard Diff Viewer & Lifetime Vault Deep Search
- **In-Memory Myers LCS Diff Engine:** Compare any two clipboard text items with split-view and unified-view side-by-side comparisons, word-level intra-line character diff highlights, and 1-click unified Git patch export.
- **Lifetime Vault Deep Search:** Full-text search engine querying historical disk payloads on demand beyond in-memory snippets, with date range filters (Today, This Week, This Month) and highlighted search match previews.

### Motioncraft 120fps GPU Compositor & Sub-50ms Press Physics
- **High-Refresh-Rate ProMotion Calibration:** Calibrated spring physics (`restDelta: 0.2`, `restSpeed: 8`) specifically tuned for 120Hz/144Hz displays with zero oscillation overshoot.
- **Sub-50ms Press Compression:** Tactile 38ms cubic-bezier press scaling (`scale(0.978)`) and 160ms fluid spring release across all cards.
- **Zero-Raster-Lag Compositor:** Complete elimination of `backdrop-filter` in scrolling tracks to ensure 120fps GPU performance on 4K multi-monitor setups.
- **FLIP Layout Reordering:** Smooth Framer Motion position tracking during pin/unpin operations with zero layout jumps.

### Kernel-Level Delta Cursor Sync & Working Set Memory Caps
- **Delta Cursor Sync (`lastSyncCursor`):** Sync engine tracks remote revision cursors, uploading and downloading only items modified since the last cursor check, cutting cloud bandwidth and Firestore reads by over 80%.
- **Power-Adaptive Background Sync:** Automatically throttles background sync intervals based on hardware power state: 20 seconds on AC power versus 300 seconds on battery power (`powerMonitor`).
- **200-Item Working Set Memory Cap:** In-memory item store caps active card payloads at 200 items, streaming older or unpinned payloads to and from disk on demand, locking operational RAM to ~130 MB even with 50,000+ lifetime items.

### Cross-Platform Native Drag-Out Staging Parity & Clean Code Formatting
- **Native Drag Parity:** Standardized drag-out file staging across Windows CF_HDROP, macOS NSFilenamesPboardType, and Linux text/uri-list, ensuring file bundles drop seamlessly into any desktop IDE, editor, or terminal.
- **Clean Code Copy:** Monospace code blocks automatically normalize mixed CRLF/LF line endings, strip trailing whitespace, and prune ghost blank lines before writing to the system clipboard.

### Configurable Global Toggle Shortcut
- **Tactile Keycap Hotkey Recorder (`<HotkeyRecorder />`):** Customize the shelf toggle shortcut (defaults to `Alt+C`) with live modifier keycap preview, instant clear/reset buttons, and non-blocking key capture.
- **Collision Detection & Dynamic Registration:** Dynamically updates Electron `globalShortcut` with automatic collision resolution and instant toast feedback.
- **Zero OS Focus Stealing:** Dynamically toggles window focusability exclusively during active key recording, keeping normal shelf clicks non-intrusive.

### Shelf Search & History Filters
- **Type-to-Filter Search Box:** Search your retained history (100 to 1000 items, default 250, adjustable in Settings). Typing never steals focus from your active app, and clicking a result pastes straight into it.
- **Elastic Filter Controls:** Rubber-band filter track (`RubberSegment`) with momentum glide and squash-and-settle selection, fully keyboard navigable with reduced-motion support.
- **Colors Filter:** Copied color codes show up under their own Colors tab as swatch cards painted with the actual color, labeled with the hex code.
- **Selective & Filter-Scoped History Clearing:** Clear history in convenient time windows (**Last 1 hour**, **6 hours**, **24 hours**, or **Clear all**) with filter-aware scoping to protect other categories.

### Universal Native OS Drag & Drop Vault
- **0ms Instant Drag-Out (Background Pre-Staging):** Pre-staging runs in the background on hover or pointerdown, ensuring temp file handles and pastel vector drag ghosts are ready before mouse drag begins.
- **Return-to-Shelf Integrity (Self-Drop Protection):** Returning dragged items back onto the shelf is a clean no-op, preventing accidental card duplication or usage count increments.
- **Click vs Drag Discrimination:** Guard threshold prevents mouse drags across text and link cards from triggering accidental click-to-paste actions.
- **External Usage Accounting:** Item usage counts (`hitCount`) and move-to-top reordering are strictly gated to drops that land in external applications.
- **Original Filename Preservation:** Images and files preserve source filenames across clipboard transfers, drag operations, and disk exports.
- **Dynamic Z-Band Demotion:** Temporarily demotes window Z-band during active drags (`setAlwaysOnTop(true, 'normal')`) to ensure smooth drag-out into all desktop apps.

### Fluid Collections & Card Stacks

- **Animated GIF Streaming:** Integrated fallback streaming via the internal protocol (`edgelocal://`), providing full animated playback for GIF files directly within stack tiles.

## Codebase & Architecture

### Process Isolation & IPC Contract
Edge-Drop is organized into three strictly isolated layers:

1. **Main Process (`electron/main/`)**: Node.js runtime handling OS integrations, Win32 OLE drag pipelines, Windows DPAPI encryption (`safeStorage`), native `ClipboardWatcher` polling, and background auto-updates (`updater.ts`).
2. **Preload Sandbox (`electron/preload/`)**: Context-isolated bridge (`contextBridge.exposeInMainWorld('edge', api)`). Consumes single-source-of-truth contracts in `shared/ipc.ts` (`InvokeMap`, `EventMap`, `SendMap`) and `shared/bridge.ts` (`EdgeApi`).
3. **Renderer Process (`src/`)**: React 18 UI powered by Zustand state management (`appStore.ts`), Web Audio synthesis (`soundEffects.ts`), and Framer Motion spring physics (`useAdaptiveSpring.ts`).

### Key Engine Components
- **`electron/backup/syncEngine.ts`**: Dual-Plane cloud sync engine featuring delta cursors (`lastSyncCursor`), power-adaptive rescheduling (20s on AC vs 300s on battery), deterministic chunked blob storage (>700 KB chunks), and SHA-256 verification.
- **`electron/backup/localVault.ts`**: Offline-resilient `.edvault` v2 snapshot engine with full payload hydration and automated rolling local backup rotations (5 timestamped snapshots with 1-click restore).
- **`electron/backup/diagnostics.ts`**: 1-click device diagnostic issue reporter collecting anonymized hardware specs, display topology, memory working set, and sync status with 1-click GitHub Issue URL generation.
- **`electron/store/ItemStore.ts`**: 200-item in-memory working set cap, on-demand disk payload streaming, binary image rehydration via `getBlob(id)`, atomic JSON persistence with `safeStorage` DPAPI encryption, and chronological sort integrity.
- **`electron/main/drag.ts`**: Cross-platform native drag-out staging parity (guaranteed `files` array across Windows CF_HDROP, macOS NSFilenamesPboardType, and Linux text/uri-list) and server-side SVG to PNG icon rendering via `@resvg/resvg-js`.
- **`electron/clipboard/ClipboardWatcher.ts`**: Polls system clipboard every 600ms. Computes cheap FNV-1a hashes over BGRA bitmap bytes for zero-overhead image deduplication.
- **`src/lib/diffEngine.ts`**: In-memory Myers LCS diff engine supporting split/unified views and word-level intra-line highlights with 1-click git patch export.
- **`src/lib/textTransform.ts`**: Pure algorithmic text transformers (JSON prettify/minify, case conversions, whitespace normalization, Markdown table synthesis).
- **`src/lib/codeFormatter.ts`**: Cross-platform code copy normalization (CRLF/LF unification, trailing whitespace removal, ghost blank line pruning).
- **`src/hooks/useAdaptiveSpring.ts`**: Calibrated ProMotion high-refresh-rate spring physics (`restDelta: 0.2`, `restSpeed: 8`) for standard and Hi-DPI displays.
- **`src/lib/soundEffects.ts`**: Synthesized Web Audio API sound suite (dial ticks, button clicks, toggle pops, delete thuds) with global toggle controls.
- **`electron/main/window.ts`**: Native Win32 window management via `koffi` (`WS_EX_NOACTIVATE`, `WS_EX_TOOLWINDOW`, `TaskbarCreated` Explorer restart recovery).

## Security

Edge-Drop touches the OS clipboard, the filesystem, and the native drag pipeline: so the security posture is intentional, not optional.

| Control | Implementation |
|---|---|
| Modern Runtime | **Electron 34.2.0+**: Patches EOL Chromium memory corruption and RCE vectors |
| Encrypted Storage | **Windows DPAPI `safeStorage`**: Plaintext history (`items.json`) encrypted at rest with user-session DPAPI keys & zero-data-loss auto-migration (`.bak` backups) |
| Process Isolation | `contextIsolation: true` · `nodeIntegration: false` · `sandbox: true` on all browser windows |
| PowerShell Hardening | Absolute executable path `${SystemRoot}\System32\WindowsPowerShell\v1.0\powershell.exe`, non-blocking `execFile`, strict path validation (`pathValidation.ts`), and queue deadlock protection |
| Protocol Confinement | `edgelocal://` canonical path resolution (`path.resolve()`) strictly confined within `%APPDATA%/Edge-Drop/images/` and SHA-256 ETag revalidation |
| Detector Teardown | Static `resources/detector.html` (zero `data:` URL inline scripts) with explicit `closed` lifecycle memory dereferencing |
| Typed IPC | `shared/ipc.ts` defines `InvokeMap`, `EventMap`, `SendMap`: channel names and payload types are statically checked on both sides |
| Privacy-Aware Clipboard | Honors `ExcludeClipboardContentFromMonitorProcessing`, `ClipboardViewerIgnore`, `CanIncludeInClipboardHistory`, `CanUploadToCloudClipboard`, plus 1Password / Bitwarden / KeePass concealed formats |
| Atomic Persistence | JSON index written via temp-file + rename; image bytes stored as per-id PNG files |
| Dev-Safe Startup | `app.setLoginItemSettings` is gated by `app.isPackaged`: dev builds never touch the Windows Registry |
| External Links | `setWindowOpenHandler` forces all window-open requests to `shell.openExternal`: no in-app navigation |

| Desktop runtime | **Electron 34+** | Direct access to native drag pipelines and multi-format clipboard streams from JS |
| Build tooling | **electron-vite** | Separate Main / Preload / Renderer builds with Vite HMR |
| UI | **React 18 + TypeScript 5.4** | Strongly typed component hierarchy |
| Audio | **Web Audio API** | Synthesized haptic audio feedback (ticks, clicks, pops, thuds) with 0 audio asset overhead |
| Animation | **Framer Motion** | Adaptive spring physics (`useAdaptiveSpring`), layout transitions, gesture animations |
| State | **Zustand** | Selector-optimized, zero cascading re-renders during drags |
| Drag icons | **@resvg/resvg-js** | Server-side SVG to PNG rendering for custom drag ghosts |
| Auto-Updates | **electron-updater** | Background downloading and single-click installation for GitHub builds |
| Cloud Sync | **Firebase REST API** | Zero-bloat lightweight REST client with delta cursor tracking and Two-Phase Commit blob storage |

## Roadmap

Edge-Drop is a production desktop clipboard vault. All 10 Major Version Epoch milestones are complete:

- [x] **Full Text Truncation Elimination & Chronological Sort Integrity** (v0.5.0): Complete payload streaming for 100k+ character items, alphabetical Firestore sort fix, chunked blob storage (>700 KB), and `.edvault` v2 snapshotting.
- [x] **Zero-Latency Shelf Keyboard Navigation & 1-9 Quick-Paste** (v0.6.0): Arrow navigation, Enter paste, Space preview, Esc collapse, illuminated Alt keycap badges, shimmering hydration skeletons, and focus ring boundary protection.
- [x] **Real-Time Sync Telemetry & Automated Rolling Backups** (v0.7.0): Sync telemetry drawer with round-trip ping latency, remote doc counts, WAL queue tracking, BYO Firebase test wizard, and automated 5-file rolling backups with 1-click restoration.
- [x] **Pinboard Workspaces & Color-Coded Tag Palettes** (v0.8.0): Ruby, Amber, Emerald, Sapphire, Violet, and Slate tag workspaces with quick-tag palette flyout, card accent strips, and tag workspace filtering tabs.
- [x] **Smart Text Transformations & In-Preview Monospace Editor** (v0.9.0): JSON Prettify/Minify, case conversions, whitespace cleaning, Markdown table synthesis, and in-preview inline monospace editing with live stats and keyboard shortcuts.
- [x] **Clipboard Diff Viewer & Lifetime Vault Deep Search** (v1.0.0): In-memory Myers LCS diff viewer (split/unified modes, word-level intra-line highlights, 1-click git patch export) and lifetime vault deep search across disk payloads with date filters and snippet highlights.
- [x] **Motioncraft 120fps GPU Compositor & Sub-50ms Press Physics** (v1.1.0): Calibrated ProMotion high-refresh-rate spring physics (`restDelta: 0.2`, `restSpeed: 8`), sub-50ms press compression (38ms cubic-bezier), zero-raster-lag FLIP layout reordering, and zero `backdrop-filter` overhead.

## Contributing

Edge-Drop is Apache-2.0 licensed and open to contributions. The best ways to help right now are:

1. **File issues**: For bugs, crashes, or privacy edge cases you encounter (especially around clipboard format detection on different apps).
2. **macOS & Linux testing**: Contributions for cross-platform platform refinements are welcome.
3. **Suggest format readers**: If you copy from an app whose content Edge-Drop mis-categorizes, open an issue with the available formats list (`clipboard.availableFormats()` output).
4. **Pick up a roadmap item**: Open an issue first to discuss scope, then send a PR against a feature branch.

All contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).

### Development workflow
```bash
npm install
npm run dev          # Electron + Vite HMR
npm run typecheck    # tsc --noEmit (node + web configs)
npm test             # Vitest test suite
npm run build:github # build Windows NSIS installer for GitHub
npm run build:store  # build Windows MSIX package for Microsoft Store
```
